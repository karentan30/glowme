## 落地方式：给中台加一个原子计数接口

中台现有 `/hub/pay/*`、`/hub/track`、`/hub/coupon/*`、`/hub/payout/*`，
**没有**任何按订单计数的账本 —— 所有子项目（glowme 出图、未来的出视频）都需要它。

`server.py` 加一张表 + 一个路由，照抄 `_hub_pay_status` 的鉴权模式：

```python
# 建表（放在其他 CREATE TABLE 旁边）
con.execute("""CREATE TABLE IF NOT EXISTS hub_order_usage(
  project_id TEXT NOT NULL, order_no TEXT NOT NULL,
  used INTEGER NOT NULL DEFAULT 0, allowed INTEGER NOT NULL,
  updated_at TEXT, PRIMARY KEY(project_id, order_no))""")

# 路由表里加一行（和 /hub/pay/status 并排）
"/hub/quota/consume": self._hub_quota_consume,

def _hub_quota_consume(self, body):
    """POST /hub/quota/consume —— 子项目扣一次额度。鉴权同 /hub/pay/create（HMAC 原始 body）。
    入参 {order_no, allowed, n=1}；只对已付款订单放行；在 _db_lock 里原子自增。
    返回 {ok, used, allowed, remaining} 或 402 {code:'QUOTA'}。"""
    v = self._hub_verify(getattr(self, "_raw_body", b"") or b"")
    if not v: self.err("鉴权失败", 401); return
    pid, _ = v
    oid     = (body.get("order_no","") or "").strip()
    allowed = int(body.get("allowed") or 0)
    n       = max(1, int(body.get("n") or 1))
    if not oid or allowed <= 0: self.err("缺少 order_no / allowed", 400); return
    now = datetime.datetime.now(datetime.timezone.utc).isoformat()
    with _db_lock:
        con = db()
        row = con.execute("SELECT status FROM orders WHERE out_trade_no=? AND project_id=?", (oid, pid)).fetchone()
        if not row: self.err("订单不存在", 404); return
        if (row[0] or "") != "paid": self.err("订单未支付", 402); return
        con.execute("INSERT OR IGNORE INTO hub_order_usage(project_id,order_no,used,allowed,updated_at)"
                    " VALUES(?,?,0,?,?)", (pid, oid, allowed, now))
        # allowed 以第一次写入为准，子项目后来传什么都改不了它
        cur = con.execute("SELECT used,allowed FROM hub_order_usage WHERE project_id=? AND order_no=?",
                          (pid, oid)).fetchone()
        used, allowed_db = cur[0], cur[1]
        if used + n > allowed_db:
            self.ok({"ok": False, "code": "QUOTA", "used": used, "allowed": allowed_db, "remaining": 0}); return
        con.execute("UPDATE hub_order_usage SET used=used+?, updated_at=? WHERE project_id=? AND order_no=?",
                    (n, now, pid, oid))
        con.commit()
    self.ok({"ok": True, "used": used + n, "allowed": allowed_db, "remaining": allowed_db - used - n})
```

glowme 侧改动（`api/generate.js`）：把出图前那句
`const used = orderGens.get(orderNo) || 0; if (used >= quota) ...`
换成先向中台 `POST /hub/quota/consume {order_no, allowed: quota}`，
返回 `ok:false` 就 402。**扣了额度但出图失败时要回退**（再打一次 n:-1，
或接口加个 `release`）—— 这点必须一起做，否则火山抽风会白扣用户额度。
