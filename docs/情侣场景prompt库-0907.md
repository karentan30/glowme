# 情侣双人场景 Prompt 库 · 0907

## 双人用法说明

- **喂 2 张正脸**：每次生成需上传两张清晰正脸参考图，第一张 = 画面**左边**的人，第二张 = 画面**右边**的人。
- **锁脸口令**：每条 prompt 开头都写「左边人保持第一张参考图的脸、右边人保持第二张参考图的脸，两人脸部特征都不改变」，别删。
- **先验保真再上**：先小批试生成 1-2 张，确认两人脸都像、没串脸/糊脸，再批量出图或换场景。若串脸，检查参考图是否正脸清晰、左右顺序是否喂反。
- **负面词保留**：每条末尾的负面词（不要 AI 感/塑料皮肤/多余手指/脸崩等）照抄，是保真关键。

## 合规红线

- **禁未成年**：参考图必须是成年人，不生成任何未成年人形象。
- **禁真名人**：不使用公众人物/明星的脸或姓名，只用用户本人及其伴侣的授权照片。
- **AIGC 标识**：生成图对外发布须标注「AI 生成」，遵守 AIGC 标识规范。
