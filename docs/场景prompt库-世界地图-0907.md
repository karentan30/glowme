# 场景 Prompt 库 · 世界地图版（0907）

> 用途：给「世界地图放大选打卡地」交互提供图生图 prompt。用户上传自拍 → 在地图上选区域/国家/城市/打卡地 → 取对应 prompt 喂图生图模型（如火山 Seedream）→ 出旅拍。

---

## 一、如何对接世界地图 UI

**交互层级**：地图 region（大区）→ country（国家）→ city/place（城市/景区）→ spot（signature 打卡地）→ prompt。

**地图 region → 本库 group 映射表**：

| 地图大区（region） | 本库 group | 覆盖国家 |
|---|---|---|
| 东亚（East Asia） | `东亚旅行` | 中国、日本、韩国 |
| 东南亚（Southeast Asia） | `东南亚旅行` | 泰国、印尼、越南、新加坡、马尔代夫 |
| 欧洲（Europe） | `欧洲旅行` | 法国、希腊、意大利…（持续扩充） |
| 美洲（Americas） | `美洲旅行` | 待补充 |
| 中东·非洲·大洋洲（MEA & Oceania） | `中东非洲大洋洲旅行` | 待补充 |

**数据取值路径**：`region → group → country → place → spot → prompt`。UI 每级下钻只需按上一级字段过滤即可。同一 place 下可有多个 spot（多机位/多造型），供用户在同一景点内选不同拍法。

**两大附类（不挂地图，走独立入口）**：
- 【婚纱国家款】：按「国家风格」选婚纱主题，不绑定具体打卡地。
- 【垂直写真】：职业/风格类写真（非地理），独立菜单进入。

**合规提示（每次生成必守）**：
1. **禁未成年**：仅限成年人形象，任何涉未成年一律拦截。
2. **禁真名人**：所有 prompt 已含「不要真实名人」，UI 侧也需拦截用户输入名人姓名/肖像。
3. **AIGC 标识**：所有产出图必须打 AI 生成标识，符合生成式 AI 内容标识要求。
4. 景点文字/门匾避免可辨真实文字（prompt 已含「不要文字」）。
